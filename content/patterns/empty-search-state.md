> Когда поиск ничего не нашёл — показываем альтернативы, популярные запросы и CTA, а не просто «ничего не найдено».

## Описание

Вместо «По запросу ничего не найдено» показываем: похожие запросы («Возможно вы искали...»), популярные категории, ссылку на поддержку, опцию «сообщить, когда появится».

## Проблема

«Ничего не найдено» — пользователь думает, что приложение не работает или у него плохой ассортимент → уходит к конкурентам.

## Решение

Превращаем «провал поиска» в точку открытия других возможностей.

## Плюсы

- Снижает bounce с пустого поиска на 25-40%
- Удерживает в funnel
- Даёт сигнал в продукт

## Минусы

- Нужна инфраструктура для похожих запросов

## Когда использовать

- E-commerce
- Контентные платформы
- Любые приложения с поиском

## Принципы и гайдлайны

### Empty state = новая точка входа

**Источник:** `nielsen`

Никогда не показывайте «ничего не найдено» без альтернатив. Дайте популярные категории, похожие запросы или CTA для подписки на появление товара.
