> Свайп вниз с обновлением контента и понятной индикацией статуса.

## Описание

Пользователь тянет список вниз → появляется индикатор → при отпускании начинается обновление → индикатор крутится → контент обновляется → спиннер пропадает с короткой анимацией.

## Проблема

Без явного способа «обновить» пользователь не понимает, актуальны ли данные. Может уйти, думая, что данные устарели.

## Решение

Pull-to-refresh — знакомый жест с понятной обратной связью.

## Плюсы

- Знакомый паттерн
- Пользователь контролирует актуальность
- Не требует кнопки

## Минусы

- Неочевиден для новых пользователей

## Когда использовать

- Ленты новостей
- Списки сообщений
- Email

## Принципы и гайдлайны

### Pull-to-refresh для живого контента

**Источник:** `hig`

Предоставьте pull-to-refresh в лентах и списках, где актуальность важна. Это знакомый жест, дающий пользователю чувство контроля.
