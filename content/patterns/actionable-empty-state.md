> Когда данных нет — показываем иконку, объяснение и CTA для создания первого элемента.

## Описание

Не «Список пуст». А: релевантная иконка, текст «У вас пока нет заказов. Оформите первый — доставка завтра!», кнопка «Перейти в каталог».

## Проблема

Пустой экран воспринимается как «приложение сломалось» или «здесь ничего нет для меня» → пользователь закрывает и не возвращается.

## Решение

Empty state = образовательный момент + CTA для действия.

## Плюсы

- Обучает пользователя
- Возвращает в funnel
- Снижает churn

## Минусы

- Нужен отдельный дизайн для каждого empty state

## Когда использовать

- Список заказов
- Избранное
- История
- Чаты
- Уведомления

## Принципы и гайдлайны

### Empty state — это первый onboarding в функцию

**Источник:** `material`

Используйте empty state, чтобы объяснить, что пользователь найдёт здесь, когда данные появятся. Включите CTA, чтобы направить к первому действию.
