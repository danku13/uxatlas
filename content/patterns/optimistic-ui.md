> При действии пользователя (like, comment) UI обновляется мгновенно, до подтверждения сервера.

## Описание

Пользователь тапнул «лайк» → сердечко сразу стало красным. Если сервер отклонил — откатываем с тихой ошибкой. Если подтвердил — ничего не делаем (всё уже готово).

## Проблема

Ожидание ответа сервера на каждое действие (500-2000мс) воспринимается как «зависло» → пользователь тапает несколько раз → дубликаты → фрустрация.

## Решение

Показываем результат мгновенно — пользователь чувствует скорость.

## Плюсы

- Perceived performance выше на 50%+
- Меньше дублирующих действий
- Ощущение «приложение летает»

## Минусы

- Сложнее обрабатывать rollback
- Нужна обработка конфликтов

## Когда использовать

- Лайки
- Комментарии
- Добавление в избранное
- Отметки

## Принципы и гайдлайны

### Optimistic updates для малозначимых действий

**Источник:** `nielsen`

Если действие легко отменить (like, save), обновляйте UI мгновенно и откатывайте при ошибке. Не заставляйте пользователя ждать подтверждения для trivial действий.
